# Muse
- Provides a platform for seamless play-alongs to learn your favorite songs.

### Key Functionality
- Voice controlled: play, pause, select songs, move back or forward in song (based on song structure: first chorus, second bridge, etc.?)
- Spotify-integrated
- With tabs from Ultimate-Guitar

### Development Process to MVP
1. Spotify-integration
2. Enable complete control over Spotify through voice eg. "Muse, go back a few seconds."
3. Create integration with Ultimate-Guitar
